# 手机号冲突找回与关联（1.3.20，流程更新至 1.3.22）

原独立演示登录页面、API、角色及模拟数据已移除。1.3.21 新增的账号密码入口是普通生产会员登录，详见《会员账号密码登录》。1.3.22 将微信身份认证与手机号验证合成一次“手机号授权登录”操作。

## 顾客流程

1. 作品库仍可由游客直接浏览。顾客主动使用预约或会员服务时点击“手机号授权登录”，确认授权后由程序依次完成微信身份认证与手机号验证。拒绝授权不新建微信账号；游客预约也不再提前自动创建占位账号。
2. 手机号未被占用或已属于当前会员时，保持原有绑定流程。
3. 微信验证出的手机号已属于其他会员时，服务端生成当前微信专属、5 分钟有效的关联申请；界面仅显示脱敏手机号，不泄露原会员姓名、余额、积分或记录。手动填写手机号不产生身份凭证，不能直接找回。
4. 原账号完全无余额、积分、业务历史、银豹关联/同步任务、个人资料或特殊等级权益时，顾客可主动确认“找回并登录”。系统保留原会员号，切换微信登录绑定，废止空的新微信占位账户。
5. 原会员有资产、记录、资料或银豹关联时，顾客出示关联码到店核验。后台在原会员行点击“关联微信”，核对本人身份、预留手机号及原会员记录，再提交顾客关联码并确认更换微信绑定。
6. 门店完成后，顾客点击“门店已确认，重新登录”。旧微信及旧令牌不再能访问原会员。顾客取消时不修改任何会员绑定，仍可继续浏览。

## 安全边界

- 保留原会员 ID、昵称、头像、手机号、会员等级/折扣、余额、积分、充值消费记录、账本、预约、留言、银豹关联及同步任务；不做账务搬迁、金额相加、记录改属或客户自动合并。
- 当前微信已有手机号、余额、积分、预约/充值/消费/账本/积分历史、留言、商品预留或银豹关联/任务时，不自动废止当前账户。需要门店核对两个账号，避免丢弃任何已有数据。
- 确认前、事务内再次检查账户、手机号凭证、会话版本、到期状态、申请未消费状态，以及两边的最新数据。新增资产/记录或绑定变化会阻止原自助请求。
- 使用现有全店写事务锁，将绑定更换、占位账号停用、申请消费、会话版本递增和审计落在同一事务中；并发确认只有一次成功。
- 新增 `Member.authVersion`，兼容原版本 0 的正常会话。找回/关联后两边的旧凭证均失效；重新微信登录只签发当前绑定的版本。旧 reviewer 角色不再被接受。
- 申请/确认审计不记录手机号、微信授权 code 或关联码明文。短期凭证仅在客户端内存和服务端存活，服务端仅保存手机号及关联码的哈希，且绑定申请人。
- 资产账户不会因仅验证当前手机号就被自助接管，防止手机号转售或回收造成原资产泄露。

## 迁移与运行

新增迁移 `20261024010000_member_phone_recovery`，仅为 Member 增加 authVersion（默认 0）、MemberLinkRequest 增加验证哈希、绑定版本和自助许可字段；不修改既有财务数据。

发布需要 API、数据库迁移、后台核验界面、小程序一并更新。已发生绑定更换后，回退服务端时必须保留 authVersion 校验，不能回退到不识别版本的鉴权实现；数据库备份用于灾难恢复，不能为回退界面而恢复覆盖真实营业数据。

原独立演示入口已取消，提审可使用正常手机号授权登录或单独提供的普通会员账号密码。若手机号对应原会员已有业务或银豹记录，仍需门店真实身份核验，不以审核身份绕过保护。
