# 消费美甲图上传与查看

管理员在“会员管理 → 使用记录”找到对应消费单，点击“上传美甲图”，选择图片后自动保存。上传后显示缩略图，可点击预览；误传的图片可用“移除图片”撤下。每笔消费最多 9 张；单张原图最多 8MB，每次合计最多 18MB，支持 JPG、PNG、WebP、HEIC/HEIF。图片上传时会去除 EXIF 等原始元数据，并压缩为最长边 1600 像素的 JPEG。

顾客在小程序“消费记录”点击“刷新消费记录”后可查看自己的照片，点击缩略图放大。现有小程序已经支持 `effectImages`，无需新增页面或更改登录、分享、支付流程。

银豹模式下，照片关联最近 100 条收银记录中的具体消费单，保存会员 ID、银豹连接账号和 customerUid 的归属快照；上传前从银豹核对该会员确有此消费单，落盘时再次检查关联。照片存在本地 `ConsumptionPhoto` 表，不向银豹写消费或修改余额、积分、折扣。原本地消费单及其旧版图片也兼容。

图片通过数据库私有字节字段保存，没有永久公开文件地址。读取消费记录时仅为对应会员的照片生成有效期一小时的只读签名链接；持有链接者在有效期内可查看，因此不要对外转发。移除图片、停用会员、切换会员登录绑定版本或改变银豹关联会阻止旧链接继续读取。移除是软删除，管理员操作有审计记录；备份仍按数据库备份保留。

新上传图片接口仅管理员可使用。普通会员只能从自己的消费记录取得链接；客户端伪造会员 ID 无效。照片上传、移除不会产生消费扣款、退款或其他账务变化。
