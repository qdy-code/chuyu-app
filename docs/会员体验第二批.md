# 会员体验第二批（1.3.6 体验版）

本批沿用现有品牌素材、配色和卡片风格；银豹仍为账务来源，小程序不新增充值、消费扣款或积分调整。美甲款式仍为可选。

## 会员侧变化

- 美甲、饰品、鲜花共用多图轮播，支持完整大图预览和图片计数。无图片时明确显示“图片待补充”，不将品牌素材伪装成作品。
- 完整展示后台描述，保留换行；参考价保留两位小数。材质、尺寸、准备时间和服务加项沿用门店已有描述或提示联系确认，不生成经营承诺。
- 空目录提供联系门店的下一步；网络失败显示重试，避免混同为无商品。
- “我的”优先展示会员卡、余额积分和下一次待确认／已确认预约；过往、取消及已完成记录不列为下一次安排。资料完善提示缩为一行，手机号留在账户资料。
- 三类预约展示每 15 分钟一项的建议时段，并保留自选分钟。占用判断按现有后台区间规则执行：未设置结束时间的预约按 30 分钟占用；区间端点相接允许，重叠禁止。这是排期校验，不是实际服务时长。
- 预约日期和过往时间按北京时间判断。读取时段失败时不允许直接提交，重试后恢复；提交前再次核对占用，后台继续执行最终冲突校验。
- 美甲可直接预约，也可在表单内取消已选款式；饰品／鲜花防止查询时段期间重复点击造成重复提交。

## 门店联系方式

用户明确暂时无法提供具体门店资料，因此本版保留“留言给门店”，不展示未确认的电话、地址、地图坐标或营业时间。

以后可在小程序 `.env.production` 设置：

```dotenv
VITE_STORE_PHONE=
VITE_STORE_ADDRESS=
VITE_STORE_HOURS=
VITE_STORE_LATITUDE=
VITE_STORE_LONGITUDE=
```

坐标须为门店确认的 GCJ-02 坐标，不能将 WGS84 或其他坐标直接填入。无坐标但有地址时提供复制地址；有完整坐标时调用地图导航。拨号和导航不要求会员登录；留言沿用现有登录与手机号要求，不自动发送内容。配置变更后重新构建和上传体验版。

## 验证与边界

- 47 项前端检查通过，包含区间边界、北京时间、时段查询失败／过期响应、下一次预约筛选与失败重试、跨会员隐私隔离、多图预览、价钱小数、重复提交及首批登录恢复回归。
- TypeScript 工具检查、19 个 Vue 页面／组件脚本类型检查，以及微信生产配置和产物检查通过。
- 本地界面检查使用实际 Vue 组件和模拟接口，不作为真实微信登录验收。原生开发者工具验证多图切换和 HTTPS 大图的实际渲染。
- 线上只读核对银豹来源、会员账户、下一次预约和三个品类的已占用时段。为多图验证建立明确标记的临时目录卡，未创建预约或修改资金。
- 后端接口和数据库结构未变化，无需后端重启或迁移。
- 上传及体验版状态以工作区 `artifacts/wechat-upload-1.3.6-receipt.json` 的实际回执为准。1.3.5 的真机确认不能自动作为本版真机结果；电话和导航待真实门店资料后单独验收。
- 仅更新体验版，不提交审核、不发布正式版。
