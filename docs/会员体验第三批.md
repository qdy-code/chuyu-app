# 会员体验第三批（1.3.8 体验版）

本批沿用现有品牌图片、米白灰蓝配色与圆角卡片。银豹仍是余额与积分的账务来源；不新增充值、扣款、退款或积分调整。

## 实现范围

- 美甲、饰品、鲜花卡片可收藏或取消收藏；“我的”新增“收藏与款式”入口，可按品类筛选收藏。
- 收藏按会员账户保存在当前设备，不同步到其他设备；退出登录后不展示，原账户重新登录后可恢复，清除小程序缓存后会丢失。页面与隐私政策说明保存方式。读取失败时不覆盖收藏，保存失败时不显示成功。
- 收藏页核对实时商品状态与参考价。下架或被他人预留的商品保留收藏，但不能直接预约；读取失败单独显示重试，不误报下架。
- “做过的美甲”只展示门店标记为已完成的美甲预约，按预约日期倒序排列。款式图是所选作品的参考图，不冒充实际完成效果；保留原消费记录入口，不承诺尚未提供的实际效果图。
- 款式记录及已完成的历史预约提供“再次预约”。只带入当前仍可预约的商品，日期、时间和备注由顾客重新选择；美甲仍可不选款式。原美甲款式下架时由顾客选择是否改为不带款式预约，饰品与鲜花下架则需重新选购。
- 再次预约仅打开申请表，不自动提交，不继承原预约的确认状态。沿用已有的登录恢复、时段查询、占用校验和门店确认流程。
- 从收藏返回饰品或鲜花页时，清除旧分类筛选，避免所选商品被旧筛选挡住。款式图预览返回时保留页面状态。

用户确认暂时没有微信订阅模板及明确权益规则，因此预约提醒与新增会员权益留待后续，不展示未配置的功能或虚构规则。

## 验证与限制

- 66 项前端回归通过，新增覆盖收藏持久化、跨会员隔离、存储失败、已完成记录筛选、下架与断网、被预留饰品、重复点击及再次预约的表单连续性。
- 21 个 Vue 页面／组件脚本类型检查、TypeScript 检查、正式配置与产物检查通过。
- 本地使用实际 Vue 组件和模拟接口检查收藏、下架提示、个人款式及重新预约表单；这些记录是本地模拟数据，不作为真实消费或真机验收。
- 线上会员预约和三个商品接口核对通过。当前真实测试会员没有已完成美甲预约，不修改真实预约状态来制造验收记录。
- 银豹实时会员接口返回 HTTP 502，提示“Token 余额不足或正式服务已暂停”；余额与积分刷新需该服务恢复后另行复核，不能记录为本批通过。
- 后端代码与数据库结构未变，无需重启、迁移或部署后端。
- 微信上传、体验版状态、开发工具质量提示和手机验收以 `artifacts/wechat-upload-1.3.8-receipt.json` 为准。临时验收目录卡仅供收藏与打开预约表单验证，不提供服务、不提交预约，真机复核后清理。
- 不提交审核，不发布正式版。
