# 会员账号密码登录

“我的”手机号授权登录按钮下提供常规“账号密码登录”，点击后展开表单。微信会员尚未填写手机号时，也能主动切换账号。正式版保留这个普通登录选项，不提供独立审核模式、模拟接口或特殊审核权限。

1.3.24 起，手机号授权登录完成后直接进入会员中心或返回未完成的预约，不再自动跳转头像昵称页。新微信会员在创建时自动保存“月光会员＋6位编号”的默认昵称，昵称不取自手机号或微信资料；重复登录不重新生成，已有会员昵称不回填、不覆盖。头像使用现有品牌默认展示，顾客可主动从账户资料或“去修改”入口修改头像昵称。账号密码登录及原会员保护保持不变。

## 账号与数据

- 账号由门店运维单独开通，不开放匿名注册或通用默认密码。
- 每个账号对应一个真实生产 Member；通过同一套普通会员接口访问自己的会员资料、预约、留言和记录。预约、留言提交后会产生真实门店记录。
- 本次审核兜底账号单独新建，余额/积分为零，不填顾客手机号、不关联银豹；没有虚构充值或消费记录。密码不在源码、小程序包或公开文档中。
- 密码登录无须微信手机号授权。手机号绑定、会员关联和找回需要微信身份，密码会话无法代替微信验证。银豹/原会员资产不会因为输入用户名而迁移或合并。
- 密码为随机盐 scrypt 哈希。连续 5 次错误后账号锁定 15 分钟；单 IP 每 15 分钟最多 10 次请求。账号/密码错误或禁用使用相同提示。
- 密码会话有效期 24 小时。禁用凭据、注销会员、调整 authVersion 后已有会话失效。关联恢复时禁用原密码凭据，需门店重新核验后重置。
- 登录密码仅在提交时发送，不写入本机存储；提交完成即清空输入框。分享继续只包含固定品牌封面和公开作品路径。

## 运维开通与重置

编译产物 `apps/api/dist/apps/api/src/provision-member-login.js` 从标准输入接收 JSON，需在已配置 DATABASE_URL 的受控运维环境执行。不得把真实密码写进命令行参数、Git 或容器镜像。

输入结构为 `{ "username": "指定账号", "password": "12至128位独立强密码", "nickname": "会员昵称" }`。用户名为 4 至 32 位英文字母、数字或下划线，统一小写。

默认只创建新的零资产会员，已有用户名会拒绝覆盖。重置时使用相同 username、指定新 password，并增加 `"rotate": true`；会递增 authVersion，使旧密码会话失效。命令只输出 username/memberId，不输出密码。开通和重置记录审计。

示例执行方式：将限制访问权限的 JSON 文件通过标准输入传给 `docker exec -i chuyu-api node /app/apps/api/dist/apps/api/src/provision-member-login.js`，操作完按门店密钥保管要求处理文件。

## 提审填写

在微信提审页面填写单独提供的账号和密码。操作路径：进入“我的”→ 阅读并勾选协议 → 点击手机号授权登录下方“账号密码登录”→ 输入账号密码 → 登录账户。若已经停留在完善手机号页面，点击下方同名入口切换即可。

该账号访问生产服务，提交预约或留言会进入真实门店后台。无需微信手机号/头像/昵称授权即可进入会员中心。真实顾客充值、消费和积分仍由银豹负责，不由本账号生成演示账务。
