# 后台手动建档与银豹同步

在“新增会员”填写手机号后，勾选“已核实顾客本人身份及手机号”，再新增会员。会员资料和同步任务在同一数据库事务中保存，不等待银豹网络；收银系统连接页可查看结果。

已手动建立但没有同步任务的会员：在“收银系统连接 → 会员核对”选择会员并查询。查不到同手机号会员时，核实身份和手机号，勾选确认后点击“同步开户到银豹”。查到候选会员时核对后关联原银豹会员，不新建。

- 门店确认单独记录为 `phoneStoreVerifiedAt`，不会伪造微信验证时间 `phoneVerifiedAt`，也不能作为微信登录、找回账号或接管原会员资产的凭证。手机号变更会清除门店确认。
- 新开户先按固定会员号和手机号检查重复；结果不确定时沿用原任务和创建意图恢复，不盲目重建。
- 银豹已有同手机号或编号冲突时进入“需核对”，不自动关联，不转移任何原会员余额、积分或记录。
- 银豹仍是余额、积分、等级和折扣的数据来源；后台建档不向银豹写入金额或积分。
- 从小程序 1.3.25 起，顾客首次微信授权同一个手机号，可直接进入尚未绑定微信的手动建档会员。系统保留原会员号、账务、历史及银豹关联，未关联的银豹任务会继续处理。已有微信绑定或两个账号均有资料时，走《手机号冲突找回与关联》的核对流程。

未填写手机号或未确认的旧版 API 请求仍可仅建立本地档案，不会自动向银豹开户。新增确认和补同步接口仅管理员可使用，操作均记入审计。
