# 会员接口节流（1.3.9 体验版）

## 行为

- “我的”、会员卡、账户资料、预约前身份检查和个人款式记录只读取本地保存的银豹投影，保留原始同步时间并明确显示为上次同步数据。登录过且资料已核对的会话五分钟内复用会员资料；未关联会员仍读取后台资料，方便及时看到门店新完成的关联。
- “刷新余额与积分”仍发起实时银豹查询，失败保留上次成功数据和同步时间，不伪装成更新成功，也不改成零余额。并发点击在客户端合并；服务器也合并同一个门店、接口和查询条件下的在途请求，不合并不同会员的查询。
- 充值、消费记录首次打开各查询一次；五分钟内再次进入或大图返回复用成功结果，跨页面实例可复用。记录显示读取时间，并提供主动刷新入口。缓存仅在当前登录会话内存中，退出、换会员或关联状态变化后清除；失败、迟到的旧会员响应不进入新会员缓存。
- 流水页不再先付费同步余额。预约、款式、留言等本地数据保留原有加载规则，不通过银豹轮询。
- 原 `GET /members/me` 保留实时读取，兼容旧版及管理员核对；新增 `GET /members/me/cached-profile` 只返回签名令牌对应会员的已保存投影。部署兼容旧版，但自动调用节省主要依赖新版体验包。

## 费用与数据边界

余额积分每次主动同步名义消耗 120 Token；充值记录 100 Token，消费记录 120 Token。被动浏览不产生余额同步费。五分钟内反复打开已读取的流水页不新增流水查询费。费用取决于实际主动操作次数，不保证固定比例。

现金、充值、消费、退款及积分调整继续由银豹负责；本次不向银豹写入会员账务，不自动补充接口额度，不改变预约要求或品牌资源。

## 验证

覆盖被动浏览零余额查询、五分钟缓存过期、主动强制刷新、完全相同在途请求合并、不同会员隔离、退出/换账号、迟到响应、失败重试，以及带款式和不带款式的原预约流程。发布配置和构建检查仍必须通过。

线上验证读取开放平台的计费余额，再多次请求缓存资料，核对同步时间与 Token 不变；主动刷新后核对会员余额、积分与同步时间。真实微信登录和手机页面的验收另行记录，不用测试令牌冒充真机验收。

只更新后端和体验版，暂不提交审核或发布正式版。
