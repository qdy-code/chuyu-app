## 本地配置

- 小程序 `release-target.json`、实际 `.env.production` 与示例已同步新 API。
- 后台实际 `.env.production`、示例及 Docker 构建专用 `deploy/admin-web.env.production` 已同步。
- Compose、Caddy、环境示例、部署脚本默认使用带 www 的主域名；不再自动拼接 www。
- `moonisle.shop` 跳转到主域名。Caddy 保留旧域名 `chuy.shop` 的 API 与图片访问，避免已安装的旧版本客户端失效；旧域名后台入口跳转到新主域名。
- 备用 Nginx 配置同步主域名；使用该配置时，证书须覆盖根域名和 www 域名。当前生产 Compose 使用 Caddy。

## 线上切换过程

首次核验：`www.moonisle.shop`、`moonisle.shop`、`chuy.shop` 均解析到 `8.133.22.99`。新域名 TLS 握手失败，旧域名后台及公开 API 仍正常。初始 SSH agent 未获得服务器登录权限。用户随后提供密钥路径，已完成下述服务器切换。

服务器需先完成以下步骤，再上传新域名客户端：

1. 保留现有 `COMPOSE_PROJECT_NAME=chuyu-app`，备份生产配置与当前 Web 镜像。将生产 `APP_DOMAIN` 改为 `www.moonisle.shop`、`CORS_ORIGIN` 改为 `https://www.moonisle.shop`，保留所有凭证和其余业务配置。
2. 使用更新后的 Caddyfile 及后台构建部署 Web，保留旧域名 API；按既有环境文件重新创建 API 以应用 CORS。无需修改数据库或执行迁移。
3. 验证新域名有效证书、后台加载、`/api/health`、真实商品及图片请求；检查新域名后台登录与 CORS，同时验证旧域名 API 仍可访问。
4. 在微信公众平台为当前 AppID 配置 request、uploadFile、downloadFile 合法域名 `https://www.moonisle.shop`，迁移期保留旧域名。
5. 新客户端使用版本 `1.3.12`，重新正式构建和上传，真机验证后再送审发布。

此前上传的 **1.3.11 仍连接 `https://chuy.shop/api`**。修改本地配置不会改变已上传的包。新目标未通过 HTTPS 验证前，不以本地构建成功代替线上切换完成。
